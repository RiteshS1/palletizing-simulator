# Overview

PalletLab teaches **robotics with C++** through one concrete, industrial problem: a robot arm has to
stack mixed cartons onto a pallet. Deciding *where* each carton goes touches almost everything a
robotics software engineer works with: geometry, physics, search algorithms, data structures,
coordinate frames, middleware like ROS 2, testing, and the warehouse systems around the robot.

## How these docs work

- **Sidebar:** chapters in a suggested order, grouped into four parts.
- **Live model:** every chapter has a 3D model next to the text, running the real plans produced by
  the C++ engine. Drag to orbit, scroll to zoom.
- **Assistant:** the button in the bottom-right corner answers questions about any chapter, the C++
  code, or robotics in general. It reads these docs and the source code before answering.

## What you will learn

| Part | You will understand |
|---|---|
| Start here | What palletizing is, what a planner outputs, how to use the simulator |
| Robotics foundations | Robot cells, frames and transforms, kinematics, ROS 2 and MoveIt, warehouse IoT, the messy real world |
| Engineering | Why robots run C++, the industry toolchain (CMake, vcpkg, GoogleTest, Eigen), WebAssembly, testing and CI/CD |
| Algorithms | AABBs, stacking rules, convex hulls, greedy vs extreme-points packing, priority queues and batching, complexity |

## What the project actually is

A C++20 planning engine (`core/`) packs a reproducible random set of cartons onto a 1200 × 1000 mm
pallet under real stacking rules, then converts each placement into a **tool pose** a robot can
execute. The same engine is wrapped as a **ROS 2 node**, and compiled to **WebAssembly** so it runs
in this website, so the simulator you see is the real planner, not a re-implementation.

<Callout title="Inspiration">
This project is inspired by the work of industry leaders in Japanese warehouse robotics, whose
intelligent palletizing and picking systems run in real factories. PalletLab is an independent
learning project.
</Callout>

## Suggested path

1. Read **What is a palletizing simulator?**, then play with the **simulator** for five minutes.
2. Work through **Robotics foundations** for the vocabulary.
3. Read **Algorithms** in order; each chapter builds on the previous one.
4. Finish with **Engineering** to see how industrial C++ projects are built, tested and shipped.
