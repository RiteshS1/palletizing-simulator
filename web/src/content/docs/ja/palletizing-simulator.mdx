# パレタイジング・シミュレーターとは

**パレタイジング** とは、箱をパレットに積み付け、ひとまとまりとしてラッピング・出荷できるようにする作業です。**パレタイジング・シミュレーター** は、実際のロボットを動かす前に（あるいは動かさずに）ソフトウェア上でその積み付けを計画・検証するためのものです。

## 単一品種と混載

- **単一品種（シングル SKU）** のパレタイジングでは、同じ箱を繰り返しのパターンで積みます。パターンは一度計算すれば一日中使い回せます。
- **混載（ミックスケース）** のパレタイジングでは、サイズも重さも違う箱が、プランナーが決められない順番でコンベヤから届きます。パレットごとに毎回計画が必要です。こちらが難しいほうで、PalletLab が解く問題です。

## ロボットセル

一般的なセルは、**搬入コンベヤ**、各箱を計測する **ビジョンシステム**、グリッパー（多くは真空吸着）を備えた **産業用アーム**、そして床テープで区画され安全柵やライトカーテンで守られた1つ以上の **パレットステーション** で構成されます。

## プランナーの出力

各箱について、配置する順に次の情報を出力します。

| 項目 | 意味 |
|---|---|
| `x, y, z` | 箱の奥・左・下の角を置く位置（mm、**パレット座標系**） |
| `sx, sy, sz` | 回転後のサイズ |
| `rotated` | 鉛直軸まわりに90°回転したか（箱は常に正立） |
| `placePose` | 箱を離すときの **ツール** の位置（m、**ロボット基準座標系**）。位置とクォータニオンで表す |
| `approachPose` | `placePose` の真上 300 mm。ロボットはここから鉛直に降下する |

これらの姿勢を、モーションプランナー（例：MoveIt）が干渉のない関節軌道に変換します。

## すべての配置が満たすルール

- パレットの範囲内、かつ高さ 1800 mm 以下。
- 他の箱と重ならない（面が接するのは可）。
- 真上から届く：その場所の上にすでに箱がない。
- 底面の75%以上が支えられ、中心が支持多角形の内側にある。
- 下の箱より重くない。
- 総重量が 1000 kg 以下。

## このシミュレーターが扱わないこと

実際のアームの運動学やアーム自体との干渉、物理シミュレーション（ルールベースの静的安定性を使用）、センサーノイズ、変形する箱。実際のシステムがそれぞれにどう対処するかは「現実世界の複雑さ」の章で解説します。
