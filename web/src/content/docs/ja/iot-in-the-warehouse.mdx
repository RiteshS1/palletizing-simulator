# 倉庫の IoT

ロボットセルは、機械とソフトウェアからなる大きなネットワークの1つのノードにすぎません。そのネットワークを理解すると、プランナーがなぜその入力を受け取るのかが分かります。

## ソフトウェアの階層

| 階層 | 答える問い | 時間スケール |
|---|---|---|
| ERP | 顧客は何を買ったか | 日 |
| WMS（倉庫管理システム） | 在庫は何がどこにあり、どの注文があるか | 時間 |
| WES（倉庫実行システム） | 今どの注文を、どのステーション・パレットで処理するか | 分 |
| WCS（倉庫制御システム） | このコンベヤを動かし、この箱を振り分け、このロボットを起動する | 秒 |
| PLC／ロボットコントローラー | 今このモーターとバルブを切り替える | ミリ秒 |

PalletLab の「注文とウェーブ」の章では、小さな WES を実装しています。

## デバイス

- **光電センサーとライトバリア** は、コンベヤ上の特定の地点を通過する箱を検出します。
- **バーコードや RFID のリーダー** は、各箱を識別します。
- **ウェイトチェッカー** は、流れている箱の重量を量ります。プランナーが重さを知る方法です。
- **3D カメラ**（構造化光、ToF、ステレオ）はサイズと姿勢を計測します。
- **真空圧センサー** は、グリッパーが箱を保持していることを確認します。
- **安全装置：** 人が入るとロボットを停止させるライトカーテン、ドアスイッチ、レーザースキャナー。

## 通信方法

- **フィールドバス**（PROFINET、EtherNet/IP、EtherCAT）は、決定論的なタイミングで PLC とドライブやセンサーを結びます。
- **OPC UA** は、PLC、ロボット、上位システムの間で構造化された機械データをやり取りするための標準です。
- **MQTT** は、ダッシュボードやクラウドへテレメトリを送る軽量なパブリッシュ／サブスクライブ型プロトコルです。
- ロボットメーカーは独自のインターフェースも提供しており、ROS 2 はその多くを橋渡しします。

## 1つの箱の旅

1. WMS が注文をリリースし、WES がそれをウェーブとパレットステーションに割り当てる。
2. WCS が箱をコンベヤで搬送し、スキャナーとウェイトチェッカーが1つずつ記録する。
3. ビジョンシステムが箱を計測し、プランナーが置き場所を決める。
4. ロボットが箱を置き、真空と位置のフィードバックで成功を確認する。
5. パレットが完成するとラッピング・ラベル貼りが行われ、そのデータが WMS へ戻っていく。

<Callout title="デジタルツイン">
デジタルツインとは、これらのセンサーから情報を受け取る、セルの生きたソフトウェアモデルです。このようなシミュレーターは、実機に触れる前に計画やレイアウトを検証するために使われます。
</Callout>
