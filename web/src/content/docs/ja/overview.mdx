# 概要

PalletLab は、ひとつの具体的な産業課題を通して **C++ によるロボティクス** を学ぶプラットフォームです。課題は「ロボットアームが、サイズの違う箱をパレットに積み付ける」こと。それぞれの箱を *どこに* 置くかを決めるだけで、ロボティクスのソフトウェアエンジニアが扱うほぼすべての要素に触れることになります。幾何、物理、探索アルゴリズム、データ構造、座標系、ROS 2 のようなミドルウェア、テスト、そしてロボットを取り巻く倉庫システムです。

## このドキュメントの使い方

- **サイドバー：** 推奨順に並んだ章を、5つのパートに分けています。
- **ライブモデル：** どの章にも本文の隣に 3D モデルがあり、C++ エンジンが実際に作った計画を再生しています。ドラッグで回転、スクロールでズームできます。
- **アシスタント：** 右下のボタンから、各章の内容、C++ コード、ロボティクス全般について質問できます。回答前にこのドキュメントとソースコードを参照します。

## 学べること

| パート | 理解できること |
|---|---|
| はじめに | パレタイジングとは何か、プランナーが何を出力するか、シミュレーターの使い方 |
| ロボティクスの基礎 | ロボットセル、座標系と変換、運動学、ROS 2 と MoveIt、倉庫の IoT、現実世界の複雑さ |
| アプリケーション | 3D 認識と点群、真空グリッパー、積み付けパターン、デパレタイジング |
| エンジニアリング | ロボットが C++ を使う理由、業界標準のツール（CMake、vcpkg、GoogleTest、Eigen）、WebAssembly、テストと CI/CD |
| アルゴリズム | AABB、積み付けのルール、凸包、グリーディ法とエクストリームポイント法、優先度付きキューとバッチ処理、計算量 |

## プロジェクトの中身

C++20 の計画エンジン（`core/`）が、再現可能なランダムな箱のセットを 1200 × 1000 mm のパレットに現実的な積み付けルールのもとで配置し、各配置をロボットが実行できる **ツール姿勢** に変換します。同じエンジンを **ROS 2 ノード** としても提供し、さらに **WebAssembly** にコンパイルしてこのサイトの中で動かしています。つまり、シミュレーターで見ているのは再実装ではなく、本物のプランナーです。

<Callout title="着想">
このプロジェクトは、日本の物流ロボティクスを牽引する企業の取り組みに着想を得ています。彼らの知能化されたパレタイジングやピッキングのシステムは、実際の工場で稼働しています。PalletLab は独立した学習プロジェクトです。
</Callout>

## おすすめの進め方

1. 「パレタイジング・シミュレーターとは」を読み、**シミュレーター** を5分ほど触ってみる。
2. 「ロボティクスの基礎」で用語を身につけ、「アプリケーション」で実際のセルが何をしているかを見る。
3. 「アルゴリズム」を順番に読む。各章は前の章を前提にしています。
4. 最後に「エンジニアリング」で、産業用 C++ プロジェクトがどう作られ、テストされ、出荷されるかを確認する。
