# デパレタイジング

サプライチェーンの反対側では、パレットが店舗や物流センターに届き、崩さなければなりません。**デパレタイジング** はパレタイジングの逆で、ある意味ではより難しい作業です。

## 難しい理由

- **配置が分からない。** このパレットを積んだのはこのロボットではありません。毎回、3D ビジョンで各箱の位置を見つけ出す必要があります（「認識とビジョン」を参照）。
- **サイズが分からない。** 取引先から届く混載パレットには、信頼できる配置データがありません。サイズはカメラに見えたものから得るしかなく、見えるのは上面だけです。
- **荷崩れ。** 輸送中に箱は傾き、ずれ、へこみます。計画どおりの場所にあるものは何もありません。

## 順番が大切：上から先に

箱をピックできるのは、その上に何も載っておらず、グリッパーが上面に届くときだけです。これは逆向きの **到達性ルール** そのもので、最上段から下へ順にピックします。同じ層の中でも、残った積み山が安定するような順番が望まれます（細くて背の高い塔を1つだけ残さない、など）。

ライブモデルは、プランナー自身の計画を **逆再生** しています。最後に置いた箱が最初に取り除かれ、グリッパーとともに持ち上がります。

## ピックのループ

1. パレット全体の点群を取得する。
2. 最上段の箱とその姿勢を検出する。
3. 到達でき、全体が見えていて、取り除いても安全な箱を選ぶ。
4. ピックして把持を確認し（真空センサー）、搬出コンベヤに置く。
5. 積み山の変化に合わせて再スキャンしながら繰り返す。

## グラフと順序

「どの箱がどの箱を支えているか」は有向グラフです。A から B への辺は、A が B の上に載っていることを意味します。正しい荷下ろしの順序はこのグラフの **トポロジカル順序**（指し示されている辺がなくなったノードだけを取り除く）であり、「上から先に」はまさにそれを実現しています。同じ構造を逆にすれば、正しい積み付けの順序になります。

## セルの評価

デパレタイジングのセルは、**1時間あたりのピック数**、**ピック成功率**、そして人が介入しなければならない頻度で評価されます。アームの速さよりも、優れた認識と慎重な次の箱の選択のほうが重要です。
