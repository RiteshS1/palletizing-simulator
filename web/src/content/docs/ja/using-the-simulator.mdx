# シミュレーターの使い方

シミュレーターには4つのモードがあり、それぞれ独立したページになっています。

| モード | 内容 |
|---|---|
| グリーディ・レイヤー | 列と層を順に埋めていく基準となる手法 |
| エクストリームポイント | 候補点を表示する、より賢いヒューリスティック |
| 並べて比較 | 同じ40個の箱に2つの手法を適用 |
| 注文 | 3店舗向けの注文が1シフトかけてパレットに積まれていく様子 |

## 操作

- オレンジのボタンまたはスペースキーで **再生／一時停止**。
- 矢印ボタンまたは矢印キーで1箱ずつ **進める／戻す**。
- **Home** と **End** で空のパレット／完成したパレットへ移動。
- 3D ビューの下の **コンベヤ** は配置1回につき1つの箱を表します。高さは箱の高さ、色は重さ（濃いほど重い）です。クリックするとその時点へ移動します。
- ドラッグでカメラを回転、スクロールでズーム、箱にカーソルを合わせると詳細を表示します。

## オーバーレイ

- **重心：** 青い球と鉛直線です。デッキ上のリングはパレットの中心を示します。良い積み付けでは、球が中心に近く、低い位置に保たれます。
- **支持多角形：** 現在の箱の下にある青い形は、その箱を支えているものすべての凸包です。オレンジの点は箱の中心で、必ずこの内側になければなりません。
- **候補点**（エクストリームポイントのみ）：アルゴリズムが現在の箱のために検討したすべての角です。オレンジがアルゴリズムの選んだ位置です。

## 別の箱で試す

右側のフォームは、**WebAssembly にコンパイルした C++ エンジン** をバックグラウンドワーカーで実行するので、ページが固まることはありません。箱の数、乱数シード、最小支持率を変えて、もう一度積み付けてみましょう。同じシードからは常に同じ箱が生成されるため、公平に比較できます。

## 数値の読み方

- **積載率：** 箱の体積 ÷ パレット全体の体積（1200 × 1000 × 1800 mm）。
- **密度：** 箱の体積 ÷（デッキ面積 × 実際の積み高さ）。積み山の中にどれだけ空気があるかを示します。
- **重心のずれ：** 重心とパレット中心との水平距離。小さいほどラッピングや輸送に安全です。
