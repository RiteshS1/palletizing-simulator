# 並べて比較

「エクストリームポイント法のほうが優れている」という主張には証拠が必要です。`bench` アプリがそれを示します。

## 公平な比較

- **同じ入力：** シードごとに、両方のパッカーにまったく同じ箱のセットを与える。
- **多数のシード：** サイズごとに50個。1つの幸運なシードでは何も証明できないから。
- **平均 ± 標準偏差：** ばらつきは平均と同じくらい重要。

| 40個の箱、50シード | グリーディ・レイヤー | エクストリームポイント |
|---|---|---|
| 配置した箱 | 55.0% ± 8.5 | **90.5% ± 5.7** |
| 積載率 | 37.4% ± 6.1 | **64.2% ± 4.2** |
| 密度 | 43.0% ± 7.1 | **65.9% ± 4.7** |
| 重心のずれ | 193 ± 37 mm | **73 ± 24 mm** |
| 計画時間 | **0.05 ms** | 3.2 ms |

エクストリームポイント法は50個中50個のシードでより多くの体積を配置し、標準偏差が小さいことから、より安定していることも分かります。

## ウェルフォードのアルゴリズム

ベンチマークは、サンプルを保存せずに **1回の走査** で平均と分散を計算します。

```cpp
void add(double x) {
    ++n;
    double delta = x - mean;
    mean += delta / n;
    m2 += delta * (x - mean);   // 分散 = m2 / (n - 1)
}
```

教科書どおりの「2乗の平均 − 平均の2乗」は浮動小数点で精度を大きく失いますが、ウェルフォードの更新式は数値的に安定しています。

## 時間計測

`std::chrono::steady_clock` は決して飛ばない（実時間の時計は同期のときに飛ぶことがある）ので、経過時間の計測に適した時計です。マイクロベンチマークでは、Google Benchmark がウォームアップ、繰り返し、Big-O の当てはめを加えてくれます。
