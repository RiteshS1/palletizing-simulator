# グリーディ・レイヤー

基準となるパッカーは、本棚に本を並べるように箱を積みます。

## アルゴリズム

1. 箱を背の高い順（同じなら重い順）に並べ、各パスでより平らな層ができるようにする。
2. デッキを x 方向の **列** に沿って進む。列の奥行きは最初の箱で決まる。
3. 各箱を **空きのある最初の列** に入れる（ファーストフィット）。なければ新しい列を作る。
4. 箱はそのまま真下にある物の上へ落ちる。
5. ルールに反した箱は次のパス（新しい層）を待つ。1回のパスで何も置けなくなったら終了。

## 貪欲法

貪欲法は、その場で最善の選択をして二度と見直しません。最適性が証明できるのは特別な構造を持つ問題（ダイクストラ法の最短経路、ハフマン符号、区間スケジューリング）だけです。積み付けではヒューリスティックにすぎず、速い反面、1つの選択が後のより良い選択をふさいでしまうことに気づけません。

## ビンパッキングは NP 困難

品物が k 個の箱に収まるかどうかの判定は NP 完全です。数のリストが合計の等しい2つのグループに分けられるか（分割問題）を考えると、それは合計の半分の大きさの箱2つに収まるかを問うのと同じです。厳密かつ多項式時間のアルゴリズムは知られていないため、産業界ではヒューリスティックを使います。

## ファーストフィット・デクリーシング

大きい順に並べ、各品物を空きのある最初の箱に入れます。1次元では、最適な箱の数のおよそ 11/9 倍以下で収まることが証明されています。私たちの列は、棚に FFD を適用したものです。

## ここで苦戦する理由

40個の箱で50個のシードを試すと、グリーディ法が配置できるのは箱の55%だけです。先に場所を選び、ルールが許すかどうかを後から確認するからです。ルールを緩めると、その影響の大きさが分かります。

| ルール | グリーディ法の積載率 | エクストリームポイント法の積載率 |
|---|---|---|
| 既定 | 38% | 64% |
| 耐荷重ルールなし | 46% | 68% |
| 支持率50% | 43% | 69% |
| 両方を緩和 | 58% | 71% |

## 計算量

並べ替えは O(n log n)。各配置で列とルールを調べるので、計画全体では最悪 O(n²) 回のルール判定になります。40個の箱で約 0.05 ms です。
