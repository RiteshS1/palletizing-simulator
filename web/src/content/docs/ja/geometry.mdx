# 幾何と AABB

積み付けのあらゆる判断は、1つの問いから始まります。この2つの箱はぶつかるか？

## 座標系

プランナーは **パレット座標系** で動作します。原点はデッキの奥・左の角、x は 1200 mm の辺、y は 1000 mm の辺に沿い、z が上です。

## 整数ミリ

積み付けは厳密な等号に依存します。「この箱の上面は、あの箱の底面とちょうど同じ高さか？」。浮動小数点ではほとんどの小数を正確に表せない（`0.1 + 0.2 != 0.3`）ため、すべての比較に許容誤差が必要になります。整数ミリならすべての比較が正確で、1 mm はどんな箱の許容差よりも細かい単位です。

## 軸平行境界ボックス

**AABB** は辺が座標軸に平行な箱で、`min` と `max` の2つの角で表します。私たちの AABB は **半開区間** `[min, max)` です。0〜100 の箱と 100〜200 の箱は接しているだけで重なってはいません。これは面と面を合わせて積む箱にぴったりの性質です。

```cpp
inline int overlap1D(int a0, int a1, int b0, int b1) {
    return std::max(0, std::min(a1, b1) - std::max(a0, b0));
}
```

2つの AABB が交差するのは、3軸すべてで区間が重なるとき **に限ります**。隙間のある軸が1つでもあれば分離されます（箱に特化した分離軸定理）。各判定は O(1) です。

## オーバーフロー

パレットの体積は 1200 × 1000 × 1800 = 2,160,000,000 mm³ で、32ビットの `int` の上限（2,147,483,647）を超えます。C++ で符号付き整数のオーバーフローは **未定義動作** なので、面積と体積は `int64_t` を使い、最初の因数をキャストして乗算全体を64ビットで行います。

## 正立のみ

箱には「天地無用」の表示があるため、鉛直軸まわりにしか回転できません。向きは6通りではなく2通りです。探索空間が小さくなる代わりに、密度がわずかに下がります。
