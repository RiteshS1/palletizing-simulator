# 認識とビジョン

ロボットが箱を置く前に、まず箱を **見る** 必要があります。どこにあり、どれくらいの大きさで、どちらを向いているのか。混載のセルでは、事前にミリ単位で分かっていることは何もないため、ピックのたびに 3D ビジョンを動かします。

## カメラから点群へ

産業用の 3D カメラは、画素ごとに奥行きを計測します。

| 方式 | 計測の仕組み | 得意なこと |
|---|---|---|
| 構造化光 | 既知のパターンを投影し、その歪みから三角測量する | 静止した対象の高精度な計測 |
| ステレオ | 2台のカメラ間で特徴点を対応付ける | 屋外光、広い範囲 |
| ToF（Time-of-Flight） | 反射光が戻るまでの時間を測る | 高速、小型のセンサー |
| レーザーラインスキャン | ライブモデルのようにレーザー線を走査する | コンベヤ上での非常に精密な形状計測 |

奥行きの画素はそれぞれ 3D の点になり、その結果が **点群**（多くは百万点規模）です。ライブモデルでは、レーザー面がパレットの上を走査し、点を高さで色分けしています。エンジニアが奥行きデータを見るときとまったく同じ見せ方です。

## 点群の中から箱を見つける

1. **分かっているものを除く：** パレットの範囲で切り出し、床とパレット自体を取り除く。
2. **平面を探す：** 箱の上面は平らな長方形です。**RANSAC**（ランダムサンプルコンセンサス）は、ランダムに3点を選んで平面を当てはめ、どれだけの点が一致するかを数え、何度も試して最良の平面を残します。外れ値を設計上無視できます。
3. **分割する：** エッジや奥行きの段差を手がかりに、各平面を個々の長方形に分けます。印刷のある箱や密着した箱には、深層学習によるセグメンテーションが役立ちます。
4. **姿勢を推定する：** 長方形の中心、サイズ、ヨー角から、カメラ座標系でのピック姿勢が得られます。
5. **変換する：** ハンドアイキャリブレーション（`T_base_camera`）をつなげて、ロボット基準座標系での姿勢を求めます。

## 高速化を支えるデータ構造

- **k-d 木** と **ボクセルグリッド** は「この点の近くにある点はどれか」に O(n) ではなく概ね O(log n) で答えます。法線推定、クラスタリング、ダウンサンプリングの土台です。
- 百万点を 1 cm のボクセルに **ダウンサンプリング** すれば、形を保ったまま処理量を10〜100分の1にできます。

## ハンドアイキャリブレーション

カメラとロボットは、物の位置について合意していなければなりません。キャリブレーションでは、カメラがターゲットを見ている間にロボットを既知の姿勢へ動かし、両者の間の固定された変換を解きます。2 mm のキャリブレーション誤差は、すべての箱で 2 mm の配置誤差になります。
